# 📊 Sales & Business Insights Dashboard

## 🚀 Overview
This project focuses on analyzing sales data to generate actionable business insights using **Power BI**. The dashboard provides a comprehensive view of revenue trends, customer segmentation, and performance metrics to support data-driven decision-making.

---

## 🎯 Objectives
- Analyze overall sales performance and revenue trends  
- Identify top-performing products and regions  
- Understand customer segmentation and behavior  
- Provide interactive insights for business decision-making  

---

## 🛠️ Tools & Technologies
- **Power BI**
- **DAX (Data Analysis Expressions)**
- **Power Query Editor**
- **Excel (Data Source)**

---

## 📂 Dataset
- Structured sales dataset containing:
  - Order details
  - Customer information
  - Product categories
  - Revenue and sales metrics  

---

## ⚙️ Data Processing
- Cleaned and transformed raw data using **Power Query Editor**
- Handled missing values and ensured data consistency  
- Created relationships between tables for efficient modeling  

---

## 📈 Key Features
- Interactive dashboard with filters and slicers  
- KPI cards showing revenue, sales, and growth trends  
- Region-wise and category-wise performance analysis  
- Customer segmentation insights  
- Time-series analysis of sales trends  

---

## 📊 Key Insights
- Identified top-performing regions contributing maximum revenue  
- Highlighted product categories with highest sales growth  
- Discovered patterns in customer purchasing behavior  
- Enabled quick comparison of business performance across dimensions
